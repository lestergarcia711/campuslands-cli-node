# CampusLands CLI Node

Ejercicio básico de Node.js desarrollado como parte del proceso de aprendizaje en CampusLands.

## Descripción

Este proyecto tiene como objetivo practicar los fundamentos de Node.js mediante una aplicación ejecutada desde la terminal.

El ejercicio está orientado a comprender cómo organizar un proyecto, ejecutar archivos JavaScript con Node.js y trabajar con módulos utilizando ECMASCRIPT.

## Tecnologías

* Node.js
* JavaScript
* ECMASCRIPT
* Terminal

## Estructura del proyecto

La estructura del repositorio está organizada de forma sencilla para facilitar el aprendizaje y mantener separados los diferentes elementos del ejercicio.

```text
campuslands-cli-node/
│
├── ...
│
└── README.md
```

La organización responde al objetivo de trabajar progresivamente los conceptos básicos de Node.js sin agregar complejidad innecesaria.

## Conceptos trabajados

Durante el desarrollo del ejercicio se practican principalmente:

* Ejecución de JavaScript con Node.js.
* Uso de módulos CommonJS.
* Importación y exportación de funcionalidades.
* Organización de archivos.
* Uso de la terminal para ejecutar el proyecto.
* Separación de responsabilidades entre archivos.
* Manejo de la lógica básica de una aplicación CLI.

## Ejecución

Para trabajar con el proyecto es necesario tener Node.js instalado.

Clonar el repositorio:

```bash
git clone https://github.com/lestergarcia711/campuslands-cli-node.git
```

Ingresar al proyecto:

```bash
cd campuslands-cli-node
```

Ejecutar el archivo correspondiente al ejercicio:

```bash
node <archivo>.js
```

El nombre exacto del archivo de ejecución depende de la estructura actual del ejercicio.

## Propósito del ejercicio

El proyecto funciona como una introducción práctica al entorno de Node.js.

La intención no es crear una aplicación grande, sino comprender correctamente las bases sobre las que posteriormente se pueden construir aplicaciones más completas.

La prioridad del ejercicio es entender cómo funciona Node.js, cómo se relacionan sus archivos y cómo utilizar module para organizar el código.
